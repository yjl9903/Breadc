# 内置能力规范

本文描述 `breadc` 在 `@breadc/core` 之上组装的默认能力。core 只提供选项动作和执行机制；其规则见 [runtime](runtime.md)。工具包划分见 [package](package.md)。

## 创建与配置

`breadc(name, init)` 将 name、version 和 description 交给 core，然后按帮助、版本的顺序注册内置选项。内置能力通过标准选项动作实现，没有独立的 help/version 子命令。

| 能力 | 默认声明 | 动作优先级 | 配置 |
| --- | --- | --- | --- |
| 帮助 | `-h, --help` | 10 | `builtin.help` |
| 版本 | `-v, --version` | 20 | `builtin.version` |

配置缺省或为 `true` 时启用；`false` 时不注册；`{ spec: '...' }` 替换选项声明，仍按 core 的声明与取值规则解析。`i18n` 支持 `en` 和 `zh`，默认英文，仅用于内置帮助文本。

```ts
const app = breadc('tool', {
  version: '1.0.0',
  i18n: 'zh',
  builtin: { help: { spec: '-H, --usage' }, version: false }
});
```

内置选项遵守普通作用域覆盖规则。后注册的同名普通选项可以替换内置动作；自定义选项动作也可以用更高优先级获选。默认情况下同时输入 help/version 时版本获选，与 argv 顺序无关。

## 显式内置动作

默认 help/version 是布尔选项，只在显式赋值为 true 时触发。因此 `--help=false` 不触发帮助动作；`-hv` 只执行优先级更高的版本动作。没有匹配命令时，仍可能满足后文的自动帮助条件。

获选内置动作保留命令匹配范围，用于展示对应帮助，但跳过位置参数数量要求、全部动作中间件和命令动作。它只转换自身选项；无关参数/选项的 cast、schema 和默认值不执行。未知选项、重复选项、缺少选项值等扫描诊断仍然抛出，不被 help/version 吞掉。

`app.parse(argv)` 只解析和转换，不打印、不执行内置动作。通过 breadc 导出的 `parse` 和 `run` 仍是 core 入口；其执行范围不附加自动帮助。

## 自动帮助

breadc 应用实例的 `run(argv)` 在解析成功后，同时满足以下条件时直接打印帮助：

- 没有匹配命令。
- 没有获选选项动作。
- 应用没有通过 `onUnknownCommand` 注册处理器。

这覆盖空输入、未知命令及没有默认命令的分组输入。自动帮助不运行 cast 或动作中间件；解析失败仍向调用方抛错。存在默认命令并成功匹配时按命令执行；匹配命令缺少 action 时也不会回退成帮助。

关闭 `builtin.help` 仅移除帮助选项，自动帮助仍可用。注册未知命令处理器后，由 core 的未知命令分支执行处理器，不再输出自动帮助。

## 帮助内容

`printHelp(context, { i18n })` 根据已解析的 Context 生成、打印并返回字符串。它读取静态声明及匹配路径，不通过执行命令或 cast 获取说明。

| 页面 | 范围和描述 |
| --- | --- |
| 根页面 | 应用描述、根级命令与分组、适用的默认命令用法 |
| 分组页面 | 分组描述、组内命令、适用的分组默认命令用法 |
| 多段路径前缀页面 | 与当前路径前缀相符的候选命令 |
| 命令页面 | 当前命令完整描述、参数、别名、有效选项及示例 |

输出以 `name/version` 开头，无 version 时显示 `unknown`。后续按条件包含描述、Usage、Aliases、Commands、Arguments、Options、Examples；空区段省略。

### 描述与示例

应用 description 可以是字符串，或 `{ description, examples? }`。命令/分组 description 可以是字符串，或 `{ summary, details?, examples? }`。每个示例为 `{ command, comment? }`。

父级命令列表只显示 summary（字符串描述则使用自身）的第一行非空文本。独立页面显示完整内容，结构化 summary 与 details 之间隔一段；换行、空段和显式缩进保留。描述不会被当作 Markdown 渲染。

示例按声明顺序展示，可选注释加 `# ` 并换行，命令文本保持字面内容和原换行，即使超过排版宽度也不截断或自动折行。示例之间留空行。

### Usage、参数与别名

Usage 根据当前位置列出命令路径、参数声明和 `[options]`（中文时为对应翻译）。根/分组同时有默认命令和子命令时，通常分别给出默认调用和子命令调用；若默认命令不带位置参数，则可合并为 `[command]` 用法。

分组列表项依据子声明区分必填子命令 `<command>`、存在默认命令时的可选子命令 `[command]`，以及只有默认命令时不显示子命令占位。

位置参数始终参与 Usage。只有至少一个参数拥有非空描述时才生成 Arguments 区段，一旦生成就包含全部参数，未写描述的条目仍保留。命令页面在有别名时展示 Aliases；根和分组范围页面不生成该区段。别名输入对应的命令 Usage 使用其主路径。

### 有效选项

帮助收集应用、当前分组和当前命令的声明，同名覆盖后只展示有效选项，失去所有权的短别名不再展示。根或分组帮助可以包含 Usage 中默认命令的选项，即使显式帮助动作让该默认命令没有进入执行匹配。

排序为普通选项、帮助、版本，各类别保持有效声明顺序。双形式布尔展开为 `--flag, --no-flag`。内置选项描述使用当前语言的“显示帮助/显示版本”，普通说明按作者原文输出。

## 排版与语言

帮助当前固定使用 80 个显示单元宽度，不读取终端宽度，也没有已接入的 logger 配置。使用 `fast-string-width` 测量可见宽度，以 grapheme 为切分单位；ANSI 样式和 OSC 链接序列不占宽度、不被拆开。

正文优先按词换行，长词按 grapheme 换行。列表统一以最长 label 决定描述列；描述列可用宽度不足 20 时，整份列表改为标签在上、描述在下的形式。Usage 能放入单行时与标题同行，否则缩进另起行。

英文/中文配置随各自应用闭包保存，不影响其他应用。`printHelp(context, { i18n: 'zh' })` 可以显式选中文；独立调用省略该参数时默认英文，不自动读取创建 breadc 时的语言设置。只有标题、占位和内置选项文案翻译，作者描述与示例保持原文。

帮助通过一次 `console.log(text)` 输出并返回该 text；生成的 text 自身以换行结束。标题使用加粗和下划线样式。

## 版本及工具导出

`printVersion(context)` 输出并返回 `${name}/${version ?? 'unknown'}`，不附加平台信息；返回字符串本身不带换行，`console.log` 负责输出换行。版本输出不受 i18n 影响，不设置退出码、不主动结束进程。

breadc 同时导出颜色、终端链接、进程清理及 TUI API。它们是显式调用的工具，没有自动接入每次命令运行的生命周期；补全生成尚未作为内置能力实现。
