# 开发文档

Breadc 按“用户意图 → 架构决策 → 源码实现”组织开发。需求说明用户要达成的目标，架构规定如何支撑这些目标，源码与测试负责实现和验证。

## 导航

- [项目开发流程](documentation.md)：三层职责、需求写法、变更顺序和完成条件。
- [用户需求](features/README.md)：原始意图、使用场景和示例。
- [架构规范](architecture/README.md)：包划分、解析、执行、类型推导和内置能力的规范索引。
- [编码规范](code-style.md)：实现约定和格式要求。
- [测试规范](testing.md)：测试重点、验证命令和覆盖率要求。

用户安装和使用说明由项目及各包 README、VitePress 文档站承载。
